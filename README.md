# NetJourney – Interactive Networking Simulator

NetJourney is an interactive educational project developed for
the Introduction to Computer Networking course.

## Project Overview

The project aims to make fundamental computer networking
concepts easier to understand through an interactive
web-based learning experience.

Instead of relying entirely on theoretical explanations,
NetJourney provides a visual learning environment for
exploring networking concepts.

## Course

Introduction to Computer Networking (ITCN)

## Unit

Unit 1 – Computer Network Fundamentals

## Technology Used

- HTML
- CSS
- JavaScript

## Running the Project

No installation is required.

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Explore the interactive learning simulator.

## Deployment

The project can be hosted using GitHub Pages.
